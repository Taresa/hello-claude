## How I work

I approach each tool the same way I approach product work: start with the problem, define requirements, and iterate fast. I use Claude Code as a development partner — handling implementation while I drive discovery, scope, and decisions. The result is software that reflects how practitioners actually work, not how engineers imagine they do.
